# Bundled fonts

The application embeds Noto Sans CJK SC Regular, Noto Serif CJK SC Regular,
Noto Sans Mono Regular, and the monochrome Noto Emoji variable font.
Text weight is rendered from regular outlines using a controlled stroke.

All fonts are distributed under the SIL Open Font License 1.1.
The license texts are included in OFL.txt, OFL-Mono.txt, and OFL-Emoji.txt.

Sources:
- https://github.com/notofonts/noto-cjk
- https://github.com/notofonts/noto-fonts
- https://github.com/google/fonts/tree/main/ofl/notoemoji

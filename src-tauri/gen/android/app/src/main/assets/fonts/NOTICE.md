# Bundled fonts

This application embeds the following fonts from the Noto CJK project:

- Noto Sans CJK SC Regular
- Noto Serif CJK SC SemiBold

The fonts are distributed under the SIL Open Font License, Version 1.1. The
complete license text is included in `OFL.txt`.

Source project: https://github.com/notofonts/noto-cjk

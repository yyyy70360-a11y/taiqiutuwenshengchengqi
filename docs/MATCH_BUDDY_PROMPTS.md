# 比赛找搭子文案

这组题材用于球友个人邀约：借比赛的参赛门槛、费用和赛程，找愿意一起去的球搭子。

在单条生成或批量生成的「题材」下，选择「比赛找搭子」分组中的任意题材，再修改「比赛条件」，点击「生成提示词」。已生成提示词时，修改题材、比赛条件、人设或语气会自动更新提示词；发送给 AI 前也可以手动编辑。

默认条件是示例：`限1–3档，免报名费，一天打完`。请按准备参加的比赛修改；也可以补充 `弹性让球`、`败方结台费` 等已确认条件。清空条件后只生成一般参赛邀约，不补充费用、档位或赛程。区域使用当前账号配置。

## 成稿口吻示例

以下均以「限1–3档，免报名费，一天打完」为示例条件。实际生成仍以界面填写的条件为准。

**直接邀约**

有没有想参加台球比赛的球搭子？限1–3档，免报名费，一天打完。想找个同城球友一起去，互相打打气。有想去的，咱们群里聊聊。

**初次参赛**

想试试比赛，又有点怕一个人去。限1–3档，免报名费，一天就能打完。有没有也想体验一下的球搭子？咱们一起去，紧张的时候还能聊两句。

**轻松体验**

不奔着冠军去，就是想体验一下比赛。限1–3档，免报名费，一天打完。有没有同城球搭子想一起去的？有人作伴，心里也踏实点。

**先练再去**

有没有想参赛的球搭子，先一起练两杆？限1–3档，免报名费，一天打完。想找个同水平的，先练练手感，再约着去试试。想一起的评论聊聊。

**带台费说明**

若条件另填「败方结台费」，费用表达示例：有没有想一起参赛的球搭子？限1–3档，报名费免了，败方结台费，一天打完。想找个同城的先练练，再一起去。群里聊聊有没有同行的。

## 事实边界

- 题材名称仅选择表达角度，不能覆盖填写的事实。例如选择「免报名费找搭子」，但条件改为报名费39元时，仍应按39元表达。
- 免报名费不等于免台费。补充了台费规则时，提示词要求保留关键费用说明。
- 人设档位与参赛档位分别表达；不能把限1–3档改成仅限3档，也不能保证没有高手。
- 不自动引用参考图中的俱乐部、联系人、电话、日期、奖项或让球细则，不虚构名次和个人经历。
- 观赛题材不能把选手的报名费、档位限制当成观众条件；需要先确认观众安排。
- 批量生成共用同一组比赛条件，变化开头、情绪和邀约方式；正文继续遵守所选海报模板的容量限制。

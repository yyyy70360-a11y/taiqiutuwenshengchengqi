# 0.1.4 渲染模板修复

- 50 套模板支持默认主题配色与自定义配色；单条修改颜色会自动切到自定义，批量可跟随每张模板的默认配色。
- 修复长话题越过卡片的问题，预留最多三行话题区域，浅色胶囊自动使用深色文字。
- 修复常用表情缺字、英文单词和档位范围被拆开、字体和字重设置不改变实际图片的问题。内置中文无衬线、中文衬线、英文等宽和表情字体，出图无需联网。
- 黑金、绿色记分牌、红色警示、紫金和粉色汽水恢复与名称对应的默认配色。
- 记分牌与对阵模板增加比赛条件卡片，仅从实际文案提取档位、报名费用与赛程，完整保留正文。免报名费不代表免台费。
- 恢复报纸与蒸汽波的独立版式，修复报纸标题分隔线斜穿画面和蒸汽波背景遮挡文字。

文案仍以「有没有想一起参赛的球搭子」为目的。档位、费用与赛程可自行填写，不自动补造比赛时间、地址、奖金或联系人。

验证包括 50 套原生 PNG 样图复查、合法长度文案边界检查、自定义颜色参数检查、字形与字重像素检查以及真正比较预期值的 SVG 快照测试。Windows 构建另在 GitHub Actions 执行测试和 Clippy。

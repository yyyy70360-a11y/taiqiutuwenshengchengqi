# Mac 端文案容量适配建议

本文档用于同步 Win10 支线的“前端提示 + 服务端校验 + 渲染自适应”改造，目标是让 macOS 客户端与 Windows 客户端继续共用同一套后台、云服务和 AI 网关，同时避免 AI 生成文案超过模板承载范围。

## 背景问题

当前 AI 生成链路只要求“文案 50-150 字”，没有把标题、正文、话题标签拆成模板级容量限制。最终出图时，如果正文过长，只能在渲染层被截断或压缩，运营侧会感觉“AI 写得挺好，但海报放不下”。

Win10 支线已经改成三层防护：

1. 前端按当前模板展示容量提示，并把模板容量写入 AI 提示词。
2. 服务端接受可选 `template` 字段，按模板校验 AI 返回内容；旧客户端不传模板时走默认 `magazine` 容量，保持兼容。
3. 本地渲染先尝试自动降低正文字号和行距，仍放不下时才加省略号。

## 建议同步范围

### 1. Mac 客户端请求 AI 时传模板 ID

AI 单条接口建议从：

```json
{ "prompt": "..." }
```

升级为：

```json
{ "prompt": "...", "template": "magazine" }
```

批量接口建议从：

```json
{ "prompt": "...", "count": 10 }
```

升级为：

```json
{ "prompt": "...", "count": 10, "template": "magazine" }
```

说明：

- `template` 是可选字段，服务端已兼容旧请求。
- 批量“统一模板”直接传统一模板 ID。
- 批量“混合模板”建议传最保守的模板 ID，即正文容量最小的模板，避免生成内容在部分模板中放不下。

### 2. Mac 前端同步模板容量提示

建议 Mac 端维护与 Win10 相同的容量表：

| 模板 ID | 标题上限 | 正文上限 | 正文行数 | 话题数量 | 单个话题 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `magazine` | 30 | 96 | 6 | 3 | 12 |
| `magazine_pro` | 30 | 112 | 7 | 3 | 12 |
| `fresh` | 30 | 112 | 7 | 3 | 12 |
| `minimal` | 30 | 136 | 8 | 3 | 12 |
| `poster` | 30 | 144 | 8 | 3 | 12 |
| `journal` | 30 | 112 | 7 | 3 | 12 |

前端显示建议：

- 单条编辑区显示：`标题 12/30，正文 84/96 字、4/6 行，话题 3/3`。
- 超限时用警告色提示，但不强制阻断用户编辑。
- 批量生成结果列表中，每条文案旁边显示同样的容量状态，方便运营手动微调。

### 3. Mac 提示词同步模板承载约束

提示词中建议新增一个独立段落，优先级高于“50-150 字”这类泛化要求：

```text
【模板承载】
当前模板：高级杂志风
标题≤30字；正文≤96字且最多6行；话题最多3个，每个≤12字。
宁可短一点，不要撑满或超出模板。
```

注意：如果保留“50-150 字”旧要求，可能和模板容量冲突。建议改为“正文像真人发的，有具体场景、个人情绪和观点”，不要再写固定 150 字上限。

### 4. Mac 渲染层同步“自适应优先”策略

渲染建议顺序：

1. 使用模板原始字号和行距排版。
2. 如果正文超过可用行数，逐级降低正文字号。
3. 字号降到下限后，再轻微压缩行距。
4. 仍然放不下时，最后一行加省略号。

建议不要直接把所有长文案截断，因为用户会觉得 AI 内容“丢了”；先缩字号更自然。

### 5. 服务端兼容点

服务端现在对 `template` 做可选处理：

- 新 Win10 / 新 Mac：传模板 ID，服务端按模板校验。
- 旧 Mac：不传模板，服务端按 `magazine` 默认容量校验。
- AI 返回超限：单条会尝试二次压缩一次；批量为控制成本，直接服务端安全收口。

## 推荐落地顺序

1. Mac 端先传 `template` 字段，不影响旧服务端，因为未知字段一般会被忽略；新服务端会立即使用。
2. 前端同步容量提示和提示词模板承载段落。
3. 渲染层同步字号/行距自适应。
4. 最后补一组长文案样例图，覆盖 6 套模板，确认不会出现正文压住话题或超出画布。

## 验收标准

- AI 单条生成后，标题、正文和话题默认不超模板容量。
- 批量生成 100 条时，列表能看到每条容量状态。
- 手动输入超长正文时，前端有提示，渲染不崩溃。
- 最终 PNG 不出现正文溢出卡片、压住话题、或文字跑出 1080x1920 画布。
- Mac 与 Win 使用同一云服务、同一后台和同一 AI 网关，不新增平台专属服务端接口。

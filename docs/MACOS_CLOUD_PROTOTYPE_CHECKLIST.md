# macOS 云端化原型施工清单

## 当前进度

> 施工进度（2026-08-18）：服务端已部署到 `115.191.33.129`，macOS 客户端云接入、后台管理、服务器 AI 配置、模板容量提示和服务端容量兜底均已进入代码库。当前重点从“能跑”转为“稳定联调”：真实域名 HTTPS、数据库备份、服务器监控、GUI 端到端回归和正式 release 回归仍待完成。

以现有 macOS Tauri + Rust 应用为原型，增加账号、云端配置同步和服务器 AI 网关，同时保留本地 Rust 渲染能力。

本阶段不做 App Store 上架，不强制签名公证；目标是自用场景下稳定安装、启动、升级和跨端复用后台。

## 总体边界

- [x] 客户端继续使用 Rust + SVG + `resvg` 本地生成 `1080 x 1920` PNG。
- [x] 服务器负责账号、用户配置、文案库同步和 AI 请求转发。
- [x] DeepSeek、通义、Kimi 等供应商 API Key 只存在服务器，不下发到客户端。
- [x] 默认不上传图片；图片继续保存到 macOS 本地输出目录。
- [x] 无网络时仍可使用模板预览、渲染和保存；需要账号或 AI 的功能显示明确状态。
- [x] 后台管理第一版已实现：管理首页、用户管理、AI 配置和 AI 调用记录。
- [ ] 本阶段不做支付、会员、公开图库、社交关系和多租户运营后台。

## 推荐架构

```text
macOS Tauri 客户端
  ├─ Rust 本地渲染器
  ├─ 本地 SQLite 缓存
  └─ Keychain 保存登录会话
          │ HTTPS / 开发期 SSH 隧道
          ▼
Rust API 服务（Axum）
  ├─ 账号与会话
  ├─ 配置和文案库同步
  ├─ AI Provider 网关
  ├─ 管理后台
  └─ 用量记录和审计
          │
          ├─ PostgreSQL
          └─ 服务器环境变量 / 后台 AI 配置
```

## 3. 服务端数据模型

- [x] `users`：用户、状态、创建时间、最后登录时间。
- [x] `sessions`：access / refresh token 哈希、过期时间、撤销时间。
- [x] `user_settings`：API 服务选择、模型、输出偏好和更新时间，不存供应商 Key。
- [x] `accounts`：用户的账号人设、区域、档位、性格和语气。
- [x] `copy_library`：标题、正文、标签和更新时间。
- [x] `usage_records`：AI 调用次数、耗时、结果状态和错误摘要，不记录 API Key。
- [x] `server_settings`：后台 AI 配置，支持 Base URL、模型、Key、超时和并发。
- [x] 所有业务表带 `user_id`，查询和更新强制带当前用户条件。
- [ ] `presets` 云端表尚未实现。
- [ ] 每条同步记录补齐 `deleted_at`、`version` 和软删除 / 可恢复策略。

## 本阶段完成标准

当以下流程全部通过，macOS 云端化原型即完成：

1. 用户在 macOS 客户端注册或登录。
2. 客户端可以同步账号配置和文案库。
3. AI 文案请求经过服务器完成，客户端看不到供应商 API Key。
4. AI 生成内容默认不超过当前模板容量，长文案渲染不压住话题或跑出画布。
5. 无网络时仍可本地渲染、保存和查看历史。
6. 重新安装或升级后，登录状态、设置和本地输出数据按预期保留。
7. 两个账号之间没有数据越权，日志和数据库中没有密钥泄露。
